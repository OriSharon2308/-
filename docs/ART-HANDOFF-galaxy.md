# מסירה לאמנות — הגלקסיה (`/galaxy`)

המסך גמור מבחינה טכנית. כל מה שמצויר עכשיו ב-CSS/SVG הוא **מציין-מקום** שמוחלף בקובץ,
בלי לגעת בקוד. המסמך הזה אומר בדיוק אילו קבצים צריך, באיזה גודל, ומה **אסור** לצייר
בתוך הקובץ — כי הקוד מוסיף את זה בעצמו (זוהר, צל, מצבים, אנימציה).

הכלל המנחה: **הקובץ מצייר את האובייקט. הקוד מצייר את האור, המצב והתנועה.**

---

## איך מתקינים קובץ

הכל דרך `galaxy-data.js`:

```js
window.GALAXY_ART = {
  ship: { body: "/images/galaxy/ship-body.webp", flame: "/images/galaxy/ship-flame.webp" },
  marks: { star: "/images/galaxy/star.svg", recommended: "/images/galaxy/recommended.svg" },
  sun: "/images/galaxy/sun.webp",
  background: "/images/galaxy/space-bg.webp",
};
```

ואיור לכל כוכב — בשדה `image` של הנושא, באותו קובץ:

```js
"שעון": { art: "clock", image: "/images/galaxy/planet-clock.webp", ring: 0.967, angle: 39, hue: "#63c9d6" },
```

`null` = מציין-המקום המצויר. אין דגל להפעיל, אין קוד להוסיף: ברגע שיש נתיב — הקובץ מחליף
את השכבה, וכל השאר (שלט, התקדמות, נגיעה, שיגור, כניסה לשיעור) ממשיך לעבוד כמו שהוא.

---

## 1. חללית — `ship-body.webp` (עדיפות גבוהה)

| | |
|---|---|
| שדה | `GALAXY_ART.ship.body` |
| פורמט | WebP (עם PNG חלופי אם צריך) |
| גודל | 256×384 (יחס 2:3 — חובה) |
| שקיפות | כן |
| כיוון | **האף כלפי מעלה**, הגוף במרכז האופקי של הקנבס |

* הקוד מסובב אותה לכיוון הטיסה, מטה אותה בפנייה (5°), מגדיל ומקטין אותה בדרך ומעלים אותה בכניסה לכוכב.
* **לא לצייר בקובץ:** להבה, זוהר-מנוע, צל, קו-תנועה, רקע.
* יחס 2:3 חשוב: אזור הפגיעה והחנייה מחושבים מהרוחב, וגובה הקובץ מגדיר את המרחק מהשמש.

## 2. להבה — `ship-flame.webp` (בינוני)

| | |
|---|---|
| שדה | `GALAXY_ART.ship.flame` |
| פורמט | WebP |
| גודל | 128×192 |
| שקיפות | כן |
| כיוון | מצביעה **למטה**, העוגן בקצה העליון-מרכזי |

* הקוד מותח אותה (עד ×1.18 ברוחב, ×1.7 באורך) לפי מצב המנוע: דומם → כיוון → הצתה → בוסט → כניסה.
* **לא לצייר:** את החללית עצמה, זוהר עגול סביב (יש שכבת-זוהר נפרדת בקוד).

## 3. שבעה כוכבים — `planet-<art>.webp` (עדיפות גבוהה)

`numbers, addition, subtraction, thinking, shapes, money, clock`

| | |
|---|---|
| שדה | `image` של הנושא ב-`galaxy-data.js` |
| פורמט | WebP |
| גודל | 512×512 |
| שקיפות | כן — הכוכב עיגול, הפינות שקופות |

* הקוד מוסיף: הילה, זוהר-מצב (טורקיז = בתהליך, זהב = הושלם), טבעת-התקדמות, כוכב-זהב, תגית "מומלץ עכשיו", הצללה למצב "טרם התחלנו", והגדלה/זוהר בקבלת החללית.
* **לא לצייר:** זוהר או צל מחוץ לעיגול, טבעת-התקדמות, סימני-מצב, שם הנושא.
* אור אחיד לכל השבעה — **מצד שמאל-עליון**.
* השפה חדה (הכוכב נראה גם בגודל 27px וגם בגודל 520px בכניסה לשיעור).
* אם האיור כבר מכיל את סמל-הנושא, האייקון מ-`/images/topics/` לא יוצג (הקוד מוותר עליו כשיש `image`).
  רוצים כוכב "נקי" והאייקון מעליו? להשאיר `image: null` ולהחליף רק את האייקון.

## 4. אייקוני-נושא — `topics/<art>.webp` (עדיפות גבוהה, ביצועים)

| | |
|---|---|
| נתיב | `/images/topics/<art>.webp` (מחליף את ה-PNG הקיים) |
| גודל | 256×256 |
| שקיפות | כן |

הקבצים הקיימים הם PNG של 0.5–1.8MB ב-1100–1254px, שמוצגים בגודל 40–90px. המרה ל-WebP
ב-256px היא השיפור הזול ביותר בטעינה של המסך.

## 5. שמש — `sun.webp` (אופציונלי)

| | |
|---|---|
| שדה | `GALAXY_ART.sun` |
| פורמט | WebP |
| גודל | 768×768 |
| שקיפות | כן — הדיסק עיגול |

* **הגודל על המסך נקבע בקוד** (80%–100% מ-27vmin, לפי כמה מקום יש לכוכב הפנימי) — הקובץ נמתח אליו.
* שם הכיתה ("כיתה א׳") נשאר טקסט HTML **מעל** האיור — לא לצייר אותו בקובץ.
* **לא לצייר:** קורונה/זוהר חיצוני (יש שלוש שכבות בקוד: glow, flare שנושמת, corona).

## 6. רקע — `space-bg.webp` (אופציונלי)

| | |
|---|---|
| שדה | `GALAXY_ART.background` |
| פורמט | WebP (או AVIF) |
| גודל | 2560×1600, מרכז בטוח 1600×1000 |
| שקיפות | לא |

* מותקן על שכבת-הרקע (`--bg`), עם `--bg-opacity` לשליטה בעוצמה. הכוכבים, הסופות והניצנוצים
  של הקוד נשארים מעליו — אם הרקע כולל כוכבים, כדאי להנמיך `--bg-opacity`.
* הרקע **לא זז** עם ה-parallax של המערכת (הוא שכבה נפרדת) — אין צורך בשוליים מיוחדים,
  אבל המרכז צריך להיות שקט: שם יושבת השמש.

## 7. סימני-משחק (אופציונלי)

| קובץ | שדה | גודל | הערות |
|---|---|---|---|
| `star.svg` | `GALAXY_ART.marks.star` | viewBox 48×48 | כוכב "הושלם". הקוד מוסיף צל חם |
| `recommended.svg` | `GALAXY_ART.marks.recommended` | viewBox 24×24 | האייקון בתוך תגית "מומלץ עכשיו" (הקפסולה עצמה נשארת CSS) |

## מה תמיד נשאר בקוד (ולא באיור)

* **מצבים:** טרם התחלנו / בתהליך (טבעת + אחוזים) / הושלם (כוכב) / מומלץ עכשיו.
* **אור ומצב:** הילה, זוהר-מצב, הצללה, אור-שפה, הגדלה ב-hover ובלחיצה.
* **תנועה:** ריחוף הכוכבים, נשימת השמש, ניצנוצים, כל השיגור (1.17–1.20 שנ') והכניסה לשיעור.
* **גאומטריה:** מקום הכוכב על המסלול, גודלו לפי עומק, גודל השמש, חניית החללית, מקום השלט —
  הכל מחושב לפי המסך ולא נצבע לתוך קובץ.
* **טקסט:** שם הנושא, אחוזים, שם הכיתה, ה-HUD — HTML אמיתי (RTL, נגישות, חיפוש).

## בדיקה אחרי התקנה (מה שנבדק כבר עם קבצי-בדיקה)

התקנת קבצים לא דורשת שינוי קוד: נבדק עם תמונות-בדיקה שהוחדרו ל-`GALAXY_ART` ול-`image`,
ובמצב הזה נשארו תקינים: אזור-הנגיעה, השלטים, טבעת-ההתקדמות, ה-hover, מסלול הטיסה,
ההחלפה לעותק-הגיבור (סטייה 0.02px), זמן הניווט (1177ms) והחזרה עם Back.

מה כן כדאי לבדוק בעין אחרי התקנה אמיתית:

1. שהכוכבים לא "יוצאים" מהעיגול (פינות לא שקופות = ריבוע מסביב).
2. שהאור בכל שבעת הכוכבים מאותו כיוון.
3. שהחללית מצביעה למעלה ושאין לה להבה מצוירת.
4. שהשמש בלי קורונה מצוירת (אחרת יש כפל-זוהר).
5. שהרקע לא מתחרה במרכז המסך.
