# דמות המורה החדש — assets

תיקיית העבודה לדמות המורה החדשה של האפליקציה.

## מבנה
- `images/full-body/`  ← **גוף מלא**. איך שהתלמיד רואה את המורה כשהוא נכנס לאתר (דף הבית/הכניסה). נוכחות מלאה.
- `images/face/`       ← **פנים בלבד**. מה שרואים בשיעורים ובתרגול — קלוז-אפ של הפנים כדי לחסוך מקום על המסך.
- `renders/`           ← לכאן ייצאו סרטוני-האנימציה שניצור (תנועה במרחב + לייב), MP4/overlay.

## שתי הפונקציות
| קטגוריה | איפה באפליקציה | תפקיד |
|---------|----------------|--------|
| גוף מלא (`full-body/`) | דף הבית / כניסה לאתר | המורה מקבל את התלמיד בנוכחות מלאה |
| פנים (`face/`) | שיעורים + תרגול | קלוז-אפ קומפקטי שלא תופס מסך |

## הערות
- מומלץ PNG עם רקע שקוף אם יש (מקל על אנימציה והטמעה), אבל כל פורמט טוב.
- שמות קבצים באנגלית/מספרים עדיפים לצינור הווידאו (למשל `full-front.png`, `face-smile.png`).

## לולאת-הריחוף — מוכנה ✓
`teacher-idle.html` — רכיב HTML/CSS עצמאי (שקוף, ללא JS): הדמות מרחפת,
זנב-הג'יני מתנועע, 13 האלמנטים צפים בקצבים שונים, וצל-קרקע "נושם" מתחת.
נבנה מהשכבות ב-`loop-src/assets/` (חיתוך: `prepare-layers.py` מ-elements.json).
- תצוגה מקומית: לפתוח את הקובץ בדפדפן (או להגיש את התיקייה בשרת סטטי).
- שיבוץ באפליקציה: להעתיק את בלוק ה-CSS/HTML של `.vela-teacher` + תיקיית assets.
- מכבד `prefers-reduced-motion` (התנועה כבויה למי שביקש).
