# ערכת Rive — המורה של vela ברמה מקצועית 🧞

Rive (https://rive.app) היא התוכנה שממנה יוצאות דמויות אינטראקטיביות
מקצועיות לאתרים ולאפליקציות (הדמויות של Duolingo, למשל). חינמית לשימוש
אישי, רצה בדפדפן, בלי התקנה.

בתיקייה הזו כל מה שצריך: השכבות החתוכות של המורה (`layers/`), תמונת-ייחוס
(`reference-full.png`), וקוד-הטמעה מוכן (`vela-rive-embed.html`).

---

## שלב 1 — פרויקט חדש וייבוא השכבות (5 דק׳)

1. נרשמים ב-rive.app → **New File**.
2. גודל Artboard: **1254 × 1254** (זה מרחב-הקואורדינטות של השכבות —
   ככה הכל מתיישב אחד-על-אחד בלי כיוונים).
3. גוררים פנימה את חמשת הקבצים מ-`layers/` (הם ממוספרים לפי סדר-ערימה,
   1 הכי מאחור):
   - `1-tail` — זנב-ההילה · מיקום X=199, Y=826
   - `2-hand` — כף-היד המנופפת · X=283, Y=464
   - `3-body` — הגוף (בלי היד ובלי עיניים פקוחות) · X=0, Y=0
   - `4-eyes-open` — עיניים פקוחות · X=492, Y=340
   - `5-eyes-closed` — עיניים עצומות · X=492, Y=340 (מעל, כבוי כברירת-מחדל)
   * המיקומים הם של הפינה השמאלית-עליונה של כל שכבה. `reference-full.png`
     היא התמונה השלמה — להשוואה שהכל התיישב.

## שלב 2 — ריגינג: עצמות בזנב (הקסם האמיתי, ~20 דק׳)

1. בוחרים את שכבת הזנב → **Rig** → יוצרים **Bone Chain** של 4–5 עצמות
   מהחיבור לגוף (למעלה, ~X=560) עד קצה הזנב (למטה).
2. Rive יציע לחבר את התמונה לעצמות עם **Mesh + Weights** — מאשרים.
   עכשיו כשמסובבים עצם, הזנב *מתעוות* כמו ערפל אמיתי, לא מסתובב כמו קרש.
3. ליד: עצם אחת לכף-היד, עם ציר-סיבוב בבסיס (ליד החפת, ~X=388, Y=600).

## שלב 3 — אנימציות (Timeline)

יוצרים שלוש אנימציות בלשונית Animate:
- **idle** (לופ 4ש׳): הגוף עולה-יורד ~12px; עצמות-הזנב מתנועעות גל
  (כל עצם באיחור קטן מהקודמת — זה מה שעושה "ערפל").
- **wave** (1.5ש׳): כף-היד ±14°, שלושה נפנופים, חזרה למרכז.
- **blink** (0.25ש׳): `4-eyes-open` נעלם, `5-eyes-closed` מופיע, וחזרה.

## שלב 4 — State Machine (האינטראקטיביות)

1. יוצרים **State Machine** → idle הוא מצב-הבית.
2. **Inputs**: `wave` (Trigger), `lookX` + `lookY` (Number ‎-1..1).
3. blink: מצב שחוזר על עצמו כל כמה שניות (Exit Time אקראי קטן).
4. מבט: **Blend State** על lookX/lookY שמטה את עצם-הגוף — או פשוט יותר:
   constraint של Translate על שכבת-העיניים.
5. ההשלמה בקוד (כבר מוכנה ב-embed): הסמן מזין את lookX/lookY,
   ואירועים באתר (תשובה נכונה!) יורים את ה-Trigger.

## שלב 5 — ייצוא והטמעה (2 דק׳)

1. **Export → Download → .riv** ← שומרים כ-`teacher.riv` בתיקייה הזו.
2. אומרים לקלוד "יש teacher.riv" — וההטמעה כבר כתובה
   (`vela-rive-embed.html`): טעינת runtime, חיבור הסמן ל-lookX/lookY,
   וה-API לאתר. שורה אחת בכל דף, כמו ברכיב הנוכחי.

מצמוץ, מעקב-סמן). Rive מחליף אותו כשה-.riv מוכן — אותו slot בדיוק.
